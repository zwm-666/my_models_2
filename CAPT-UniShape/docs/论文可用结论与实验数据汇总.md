## 一、论文标题与核心主张

**论文标题建议**：CAPT-UniShape: Condition-Aware Prototype Transport for Multi-Modal PEMFC Fault Classification

**核心主张**：
1. 提出 CAPT-UniShape 模型，融合电堆运行序列、EIS/阻抗形状序列和工况变量三种输入，用于 PEMFC 故障分类。
2. 引入 Residual KAN-Fusion 实现多源非线性特征融合。
3. 引入 RBF 工况感知动态原型分类头（CAPT），使类别原型随工况自适应迁移。
4. 在自测 PEMFC 数据集上，所提模型在 8:2 主协议下达到 100.00% Accuracy 和 100.00% Macro-F1，优于传统机器学习和深度学习基线。

## 二、模型结构摘要（供方法章节使用）

### 2.1 输入

| 输入 | 符号 | 形状 | 含义 |
|---|---|---|---|
| 电堆运行序列 | x_op | [B, 3, 64] | 电堆总电压、总电流、功率 |
| EIS/阻抗形状序列 | x_eis | [B, 4, 128] | 由 9 个阻抗统计量构造的 4 通道形状序列 |
| 工况变量 | x_cond | [B, 12] | 9 个阻抗/EIS 统计量 + 3 个电堆变量 |

### 2.2 模块组成

| 模块 | 作用 |
|---|---|
| Official UniShape Backbone ×2 | 分别编码 x_op 和 x_eis 的多尺度形状特征（共享结构、不共享权重） |
| Condition Encoder | MLP 将 x_cond 映射到 d_model 维条件 token |
| 工况门控 | σ(Linear(z_cond)) 动态加权 op/eis 分支贡献 |
| Residual KAN-Fusion | MLP 主分支 + KAN 残差分支 + FiLM 工况调制 |
| RBF Prototype Head (CAPT) | 静态原型 + RBF 工况偏移 → 余弦/温度分类 |

### 2.3 损失函数

```
L = L_wce + α_transport·L_transport + α_sep·L_sep + α_kan·L_kan
```

- L_wce：sqrt_balanced 类别加权交叉熵
- L_transport：原型迁移幅值正则（α=0.001）
- L_sep：原型分离正则（α=0.001）
- L_kan：KAN 基函数正则（α=0.0001）

### 2.4 关键超参数

| 参数 | 值 |
|---|---|
| d_model | 128 |
| hidden_dim / fusion_hidden_dim | 256 |
| kan_bottleneck_dim | 32 |
| kan_num_basis | 8 |
| temperature | 0.07 |
| num_rbf_centers | 16 |
| channel_aggregation | attention |
| scale_len | 3 |
| 参数量 | 6,489,373 |

## 三、实验设置摘要（供实验章节使用）

### 3.1 数据

- 来源：自测 PEMFC 测试数据（`data/raw/测试数据.xlsx`）
- 总样本：433 个滑动窗口（window_size=64, stride_train=16, stride_eval=32）
- 三分类：类别 0（正常）、类别 1、类别 2（过湿）
- EIS 构造：9 个阻抗统计量插值到 128 点 + 一阶差分 + 累积形状 + 频率坐标 → 4 通道

### 3.2 数据划分

- 基于连续工况片段的分组分层划分（segment_gap=600s, block=300s）
- group_split_strategy: holdout_first
- 8:2 主协议：训练 311 样本、验证 67 样本、测试 55 样本
- 测试集类别分布：类别 0 = 8, 类别 1 = 11, 类别 2 = 36
- 归一化统计量仅由训练集计算

### 3.3 训练

- 优化器：AdamW (lr=1e-4, weight_decay=1e-4)
- batch_size=32, epochs=80, patience=10
- 类别权重：sqrt_balanced
- 早停指标：验证集 Macro-F1（3 轮移动平均）
- 不做 train+val 重训（refit_trainval=False）

## 七、消融实验结果（8:2 协议，seed=44）

| 变体 | 模块变化 | Accuracy | Macro-F1 | 第0类 Recall | 第0类 F1 |
|---|---|---|---|---|---|
| **full_rbf（完整模型）** | 全部模块 | **100.00%** | **100.00%** | **100.00%** | **100.00%** |
| no_rbf | 去掉 RBF 动态原型头 → MLP 分类头 | 98.18% | 96.33% | 87.50% | 93.33% |

| static_prototype | 保留原型但关闭工况迁移 | 100.00% | 100.00% | 100.00% | 100.00% |
| no_transport_reg | 去掉原型迁移正则 | 100.00% | 100.00% | 100.00% | 100.00% |
| no_separation_reg | 去掉原型分离正则 | 100.00% | 100.00% | 100.00% | 100.00% |
| no_eis_input | 置零 EIS 分支 | 87.27% | 82.99% | 62.50% | 58.82% |
| no_condition_input | 置零工况向量 | 100.00% | 100.00% | 100.00% | 100.00% |
| stack_only | 仅电堆运行分支 | 83.64% | 79.95% | 75.00% | 85.71% |
| eis_cond_only | 仅 EIS + 工况 | 100.00% | 100.00% | 100.00% | 100.00% |

### 消融结论

1. **RBF 动态原型头有效**：去掉后 Macro-F1 降 3.67 个百分点，第0类 Recall 降 12.50 个百分点。
2. **Residual KAN-Fusion 有效**：去掉后 Macro-F1 降 7.54 个百分点，第0类 Recall 降 25.00 个百分点。
3. **EIS/阻抗形状是核心判别信息**：置零后 Accuracy 降 12.73 个百分点，第0类 F1 降 41.18 个百分点。
4. **static_prototype / no_transport_reg / no_separation_reg 在单 seed 下未体现差异**：论文中应谨慎表述，不宜宣称这些子模块在所有划分下均带来稳定提升。

## 十、论文写作注意事项

### 必须做的

1. 同时报告 Accuracy 和 Macro-F1（类别不均衡，Accuracy 会掩盖少数类问题）。
2. 报告第0类 Recall/F1 和 Support（正常类样本最少，是关键安全类别）。
3. 消融实验中 static_prototype 等仍为 100% 的变体，应诚实报告并解释为"单 seed 下边际贡献不敏感"。
4. 噪声实验中所提模型不是所有 SNR 下都优于基线，应如实描述。
5. 多 seed 均值应放入正文或附录，避免只报告最优单次结果。

### 不能做的

1. 不能宣称"所有设置下均显著优于所有基线"——传统 SVM 在多 seed 均值上表现较强。
2. 不能只报告 100% 主结果而完全省略多 seed 波动。
3. 不能把噪声增强训练的结果混入干净训练主结果表。
4. 不能把 noise_std 口径和 SNR 口径的数值直接放在同一张表里比较。

### 建议的论文结构

1. Introduction：PEMFC 故障分类挑战 + 多源融合 + 工况感知动态原型的动机
2. Related Work：UniShape / KAN / Prototype Learning / PEMFC 诊断
3. Method：模型结构（2.2 节内容）+ 损失函数 + 训练策略
4. Experiments：
   - 4.1 数据集与实验设置
   - 4.2 主结果与基线对比（第四、五节）
   - 4.3 不同比例实验（第六节）
   - 4.4 消融实验（第七节）
   - 4.5 噪声鲁棒性分析（第八节）
   - 4.6 噪声增强训练补充（第八节 8.3）
5. Discussion：模型优势、局限性、第0类敏感性、未来工作
6. Conclusion

4. 在自测 PEMFC 数据集上验证模型有效性，并通过消融和噪声实验分析各模块贡献

### 13.4 语言和表述修改

| 现有表述 | 问题 | 建议修改 |
|---|---|---|
| "deliberately conservative" | 不适合学术论文 | 删除，用数据说话 |
| "should not be read as evidence that..." | 过度防御 | 改为 "Note that this result is obtained from a single seed..." |
| "The claim made here is kept deliberately limited" | 不自信 | 删除，直接描述方法 |
| "These results suggest that..." (反复出现) | 过于弱化 | 适当使用 "demonstrate" 或 "indicate" |
| "best framed as strong split-specific evidence" | 啰嗦 | 简化为 "achieved under the evaluated protocol" |
| "rather than as a general performance guarantee" | 每段都有类似表述 | 集中在 Discussion 说一次即可 |

**总体语言建议**：
- 正文用正面、客观的语言描述结果
- 局限性集中在 Discussion 和 Conclusions 的 future work 部分
- 不需要在每个结果后面都加 disclaimer
