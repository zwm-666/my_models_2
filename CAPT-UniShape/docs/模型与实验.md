# 消融实验与噪声测试实验设计说明

> 本文档面向 AI 写作助手，说明消融实验和噪声测试实验的设计思路、数据处理方式和评价方法，用于撰写论文实验章节。

---

## 一、实验目标

### 1.1 消融实验

验证 CAPT-UniShape 各关键模块对故障分类性能的贡献，回答以下问题：
1. RBF 工况感知动态原型头是否优于普通 MLP 分类头？
2. Residual KAN-Fusion 的 KAN 残差分支是否有必要？
3. 工况感知原型迁移（prototype transport）是否优于静态原型？
4. 各输入模态（电堆运行序列、EIS/阻抗形状、工况变量）各自贡献多大？

### 1.2 噪声测试实验

评估模型在传感器噪声干扰下的鲁棒性，回答以下问题：
1. 所提模型在不同信噪比（SNR）下的性能衰减程度如何？
2. 与对比模型相比，所提模型的抗噪能力如何？
3. 哪个输入模态对噪声最敏感？

## 二、数据说明

### 2.1 数据来源

原始数据为自测 PEMFC 电堆故障测试数据，包含 216 个单片电压、电堆总电压/总电流/功率、9 个阻抗/EIS 统计特征，以及多个运行工况变量（压力、温度、流量等）。三分类标签：类别 0 = 正常，类别 1 = 膜干，类别 2 = 水淹。

### 2.2 模型输入构成

模型接收三类输入：

| 输入 | 符号 | 形状 | 内容 |
|---|---|---|---|
| 电堆运行序列 | x_op | [N, 3, 64] | 电堆总电压、总电流、功率的滑动窗口（window=64） |
| EIS/阻抗形状序列 | x_eis | [N, 4, 128] | 由 9 个阻抗统计量构造的 4 通道形状序列 |
| 工况变量 | x_cond | [N, 7] | 7 个独立工况变量 |

### 2.3 EIS/阻抗形状序列的构造方法

由于当前数据中没有原始全频 EIS 频谱，模型使用 9 个阻抗统计量（总阻抗、平均阻抗、最高阻抗、次高阻抗、最低阻抗、次低阻抗、标准差、EIS 电阻实部、EIS 电阻虚部）构造研究可用的形状序列：

1. 将 9 个统计量视为有序曲线，在归一化频率坐标上插值到长度 128
2. 计算一阶差分序列（局部变化趋势）
3. 计算中心化累积形状（整体形态）
4. 附加归一化频率坐标通道

最终得到 4 通道 × 128 点的形状序列。

### 2.4 工况变量的选取

工况变量通过 RF 重要性 + ANOVA F-ratio + 相关性去重筛选，最终保留 7 个与故障类别相关且彼此正交的独立工况变量：

| 序号 | 变量 | 物理含义 |
|---|---|---|
| 1 | 进堆空压 | 空气侧压力 |
| 2 | 出堆水温 | 冷却系统温度 |
| 3 | 高压水泵转速 | 冷却系统控制量 |
| 4 | 氢压差 | 氢气侧压降 |
| 5 | 空压差 | 空气侧压降 |
| 6 | 水温升 | 冷却水温升 |
| 7 | FC空压机出口温度 | 压缩热指标 |

这些变量与 x_op（电堆运行时间序列）和 x_eis（阻抗形状）在信息层面正交，代表电堆的运行工况环境。

### 2.5 数据划分

采用基于连续工况片段的分组分层划分：
- 按测试时间排序，当相邻记录时间间隔超过 600 秒或标签变化时开启新 segment
- 较长片段切分为 300 秒 block
- 按 group 级别分层抽样，避免同一连续片段同时进入训练集和测试集
- 归一化统计量仅由训练集计算

当前 8:2 协议（seed=44）的划分结果：
- 训练集：317 个窗口
- 验证集：54 个窗口
- 测试集：66 个窗口（类别 0 = 7, 类别 1 = 11, 类别 2 = 48）

## 三、模型结构

### 3.1 整体架构

CAPT-UniShape 由四个主要模块组成：

1. **双分支 UniShape 骨架**：分别编码 x_op 和 x_eis，提取多尺度形状特征
2. **工况编码器**：MLP 将 7 维工况变量映射到 d_model=128 维条件 token
3. **Residual KAN-Fusion**：融合三个分支的表示，包含 MLP 主分支 + KAN 残差分支 + FiLM 工况调制
4. **RBF 工况感知动态原型头**：根据工况 token 生成类别原型偏移，用余弦相似度/温度分类

### 3.2 前向流程

```
z_op   = UniShape_op(x_op)          → [B, 128]
z_eis  = UniShape_eis(x_eis)        → [B, 128]
z_cond = ConditionEncoder(x_cond)   → [B, 128]

g_op  = sigmoid(Linear(z_cond))     # 工况门控
g_eis = sigmoid(Linear(z_cond))
z_fused = g_op·z_op + g_eis·z_eis + z_cond

h = ResidualKANFusion(z_fused, z_cond)   → [B, 128]

dynamic_prototype_k = static_prototype_k + RBF_mapper(z_cond)_k
logit_k = cos(h, dynamic_prototype_k) / τ
```

### 3.3 超参数与训练设置

所提模型和所有对比模型的完整超参数、训练配置详见 `configs/current_comparison_models.yaml`。

## 四、消融实验设计

### 4.1 消融变体

所有变体使用**相同的数据划分和训练协议**，仅改变模型结构或输入：

| 变体 | 变化内容 | 验证的假设 |
|---|---|---|
| **full_rbf**（基准） | 完整模型 | — |
| no_rbf | 去掉 RBF 动态原型头，换为 MLP 分类头 | RBF 动态原型的贡献 |
| no_kan_fusion | 关闭 KAN 残差分支，只保留 MLP 融合 | KAN 非线性融合的贡献 |
| static_prototype | 保留原型分类但关闭工况迁移（Δp=0） | 工况感知迁移的贡献 |
| no_eis_input | 将 x_eis 置零 | EIS/阻抗形状信息的重要性 |


### 4.2 消融实验的实现方式

- **结构消融**（no_rbf, no_kan_fusion, static_prototype）：修改模型配置中的开关参数，让模型在构建时跳过对应模块
- **输入消融**（no_cond）：将 NPZ 中对应输入数组置零后，用完整模型重新训练

每个变体都是**独立重新训练**的，不是加载已有 checkpoint 后关闭模块。

### 4.3 评价指标

- Test Accuracy
- Test Macro-F1（主指标，因为类别不均衡）
- Test Weighted-F1
- 参数量
- 推理时间

## 五、噪声测试实验设计

### 5.1 实验协议

1. 所有模型在**干净训练集**上训练完成
2. 验证集用于选择最佳 checkpoint
3. 仅对**测试集**的输入加入噪声
4. 用训练好的 checkpoint 在噪声测试集上评估
5. 报告性能下降幅度

### 5.2 噪声参数化方式（SNR 口径）

采用信噪比（SNR, dB）作为噪声强度参数：

```
噪声功率 = 信号功率 / 10^(SNR/10)
```

SNR 越低，噪声越强。测试的 SNR 级别：clean, 40dB, 30dB, 20dB, 10dB, 5dB, 0dB

噪声类型：高斯白噪声，同时作用于 x_op、x_eis 和 x_cond 三个输入。

### 5.3 对比模型

对比模型包括：Logistic Regression、SVM、Random Forest、MLP、1D-CNN、Transformer、iTransformer，以及所提 CAPT-UniShape。各模型的具体配置详见 `configs/current_comparison_models.yaml`。

所有模型使用相同的数据划分和相同的测试集，确保公平比较。

### 5.4 评价指标

- Test Accuracy 及其下降幅度
- Test Macro-F1 及其下降幅度
- 第 0 类 Recall（正常类对噪声的敏感性）
- 推理时间

### 5.5 噪声实验的论文表述要点

- 所有模型均在干净数据上训练，噪声仅加在测试集
- 这模拟的是实际部署中传感器噪声、阻抗测量误差和工况记录偏差的影响
- 应同时报告 Accuracy 和 Macro-F1，因为类别不均衡时 Accuracy 可能掩盖少数类问题
- 如果所提模型在某些 SNR 下不如基线，应如实报告并分析原因

## 七、写作注意事项

1. **消融实验中如果某些变体仍达到 100%**（如 static_prototype），应诚实报告，表述为"在当前单 seed 划分下边际贡献不敏感"，不要回避
2. **噪声实验中如果所提模型不是所有 SNR 下都最优**，应如实描述，可以分析原因（如 RBF 余弦分类对输入扰动敏感）
3. **第 0 类正常样本测试支持数仅 7 个**，单个样本的误判会显著影响类别指标，论文中应说明这一点
4. **消融和噪声实验使用相同的数据划分**，确保结果可比
5. 结果统一用百分数，百分数保留 2 位小数
