## 三、消融实验

### 3.1 已有消融脚本

脚本路径：`scripts/run_official_ablation_experiments.py`

运行方式：
```bash
python scripts/run_official_ablation_experiments.py \
  --data <NPZ路径> \
  --variants <变体列表> \
  --output-root <输出目录> \
  --data-root <数据变体目录> \
  --epochs 80 \
  --patience 10 \
  --seed 44 \
  --batch-size 32 \
  --class-weighting sqrt_balanced \
  --lr 0.0001 \
  --weight-decay 0.0001 \
  --min-epochs-before-stop 20 \
  --val-metric-smoothing 3
```

### 3.2 消融变体定义

脚本中已定义的变体（`ABLATIONS` 字典）：

| 变体名 | 配置文件 | 覆盖参数 | 数据操作 | 说明 |
|---|---|---|---|---|
| `full_rbf` | `configs/rbf_kanfusion.yaml` | 无 | 无 | 完整模型（基准） |
| `no_rbf` | `configs/kanfusion_no_rbf.yaml` | 无 | 无 | 去掉 RBF 头 → MLP 分类器 |
| `no_kan_fusion` | `configs/rbf_kanfusion.yaml` | `use_residual_kan_fusion: false` | 无 | 关闭 KAN 残差分支 |
| `static_prototype` | `configs/rbf_kanfusion.yaml` | `use_condition_transport: false` | 无 | 关闭工况迁移 |
| `no_transport_reg` | `configs/rbf_kanfusion.yaml` | `alpha_transport: 0.0` | 无 | 去掉迁移正则 |
| `no_separation_reg` | `configs/rbf_kanfusion.yaml` | `alpha_sep: 0.0` | 无 | 去掉分离正则 |
| `no_eis_input` | `configs/rbf_kanfusion.yaml` | 无 | 置零 `x_eis` | 验证 EIS 贡献 |
| `no_condition_input` | `configs/rbf_kanfusion.yaml` | 无 | 置零 `x_cond` | 验证工况贡献 |
| `stack_only` | `configs/rbf_kanfusion.yaml` | 无 | 置零 `x_eis` + `x_cond` | 仅电堆运行 |
| `eis_cond_only` | `configs/rbf_kanfusion.yaml` | 无 | 置零 `x_op` | 仅 EIS + 工况 |
| `fixed_equal_fusion` | `configs/rbf_kanfusion.yaml` | `use_condition_gating: false` | 无 | 去掉工况门控 |
| `no_film` | `configs/rbf_kanfusion.yaml` | `use_film_modulation: false` | 无 | 去掉 FiLM 调制 |

### 3.3 消融实验的工作原理

1. **结构消融**（no_rbf, no_kan_fusion, static_prototype 等）：通过修改 config 中的开关参数，让模型在构建时跳过对应模块。
2. **正则消融**（no_transport_reg, no_separation_reg）：将对应损失权重设为 0。
3. **输入消融**（no_eis_input, stack_only 等）：先把 NPZ 中对应的输入数组置零，再用相同模型训练。

每个变体都是**独立重新训练**的，不是加载已有 checkpoint 后关闭模块。

### 3.4 消融实验的完整命令示例

```bash
python scripts/run_official_ablation_experiments.py ^
  --data data/processed/codex_baseline_selected_self_seed44_8_2/official_self_stack_impedance_eis_w64_8_2.npz ^
  --variants full_rbf no_rbf no_kan_fusion static_prototype no_transport_reg no_separation_reg no_eis_input no_condition_input stack_only eis_cond_only ^
  --output-root results/ablation_final_seed44_8_2 ^
  --data-root data/processed/ablation_final_seed44_8_2 ^
  --epochs 80 ^
  --patience 10 ^
  --seed 44 ^
  --batch-size 32 ^
  --class-weighting sqrt_balanced ^
  --lr 0.0001 ^
  --weight-decay 0.0001 ^
  --min-epochs-before-stop 20 ^
  --val-metric-smoothing 3
```

### 3.5 输出格式

每个变体输出到 `<output-root>/<variant>/`，包含：
- `metrics.json`：完整指标（含 val 和 test）
- `confusion_matrix.csv`
- `predictions.csv`
- `best.ckpt`（如果 `run_training` 保存了的话）

汇总文件：`<output-root>/summary.csv`

### 3.6 注意事项

- `configs/rbf_kanfusion.yaml` 中 `epochs: 5` 是调试用的，实际跑消融时通过 `--epochs 80` 覆盖
- `d_model=96`（rbf_kanfusion.yaml）vs `d_model=128`（kanfusion_no_rbf.yaml）：两个配置的 d_model 不同，这是设计如此（NoRBF 版用更大的 d_model 补偿没有 RBF 头的表达力）
- 消融实验应使用**相同的数据划分**（同一个 NPZ 文件），只改变模型结构或输入

## 四、噪声测试实验

### 4.1 两种噪声口径

项目中有两种噪声参数化方式，**不能混用**：

| 口径 | 参数 | 含义 | 脚本 |
|---|---|---|---|
| noise_std | 0.00, 0.01, 0.03, 0.05, 0.10 | 相对标准差（噪声 = std × signal_std） | `run_official_noise_experiments.py` |
| SNR (dB) | 40, 35, 30, 25, 20, 15, 10, 5, 0 | 信噪比（噪声功率 = 信号功率 / 10^(SNR/10)） | `refresh_snr_noise_results.py` |

**建议论文使用 SNR 口径**，因为它更标准、更容易与其他论文对比。

### 4.2 噪声实验协议

1. 所有模型在**干净训练集**上训练
2. 验证集用于选 checkpoint
3. 仅对**测试集**的 `x_op + x_eis + x_cond` 加噪声
4. 用训练好的 checkpoint 在噪声测试集上评估
5. 报告 Accuracy、Macro-F1、第0类 Recall 的下降

### 4.3 SNR 噪声实验脚本

脚本路径：`scripts/refresh_snr_noise_results.py`

该脚本是**训练 + 噪声测试一体化**的：
1. 先在干净数据上训练所有模型（proposed + 基线）
2. 保存 checkpoint
3. 对测试集按不同 SNR 加噪声
4. 用 checkpoint 评估每个噪声级别
5. 输出 summary.csv

### 4.4 SNR 噪声实验的完整命令

```bash
python scripts/refresh_snr_noise_results.py ^
  --clean-npz data/processed/codex_baseline_selected_self_seed44_8_2/official_self_stack_impedance_eis_w64_8_2.npz ^
  --output-root results/noise_final_seed44_8_2 ^
  --data-root data/processed/noise_final_seed44_8_2 ^
  --models logreg random_forest mlp cnn1d transformer itransformer proposed ^
  --proposed-config configs/rbf_kanfusion.yaml ^
  --snr-dbs 40 35 30 25 20 15 10 5 0 ^
  --noise-targets x_op x_eis x_cond ^
  --seed 44 ^
  --epochs 80 ^
  --proposed-epochs 80 ^
  --patience 10 ^
  --min-delta 0.0001 ^
  --batch-size 32 ^
  --lr 1e-3 ^
  --weight-decay 1e-4 ^
  --proposed-lr 1e-4 ^
  --proposed-weight-decay 1e-4 ^
  --hidden-dim 64 ^
  --d-model 64 ^
  --num-layers 2 ^
  --dropout 0.1 ^
  --rf-estimators 200 ^
  --no-refit-trainval ^
  --min-epochs-before-stop 20 ^
  --val-metric-smoothing 3 ^
  --class-weighting sqrt_balanced ^
  --selection-score macro_f1 ^
  --skip-workbook
```

### 4.5 噪声加入方式（SNR 口径）

代码逻辑（来自 `refresh_snr_noise_results.py` 的 `write_test_subset_with_snr_noise`）：

```python
# 对每个目标字段（x_op, x_eis, x_cond）：
signal_power = mean(signal^2)
target_noise_power = signal_power / 10^(snr_db / 10)
noise = randn(shape) * sqrt(target_noise_power / mean(noise^2))
noisy_signal = signal + noise
```

即：按目标 SNR 计算所需噪声功率，生成高斯噪声并缩放到目标功率，然后加到信号上。

### 4.6 基线模型定义

`refresh_snr_noise_results.py` 中的基线模型：

| 模型名 | 类型 | 实现方式 |
|---|---|---|
| `logreg` | sklearn | `LogisticRegression` + `StandardScaler` pipeline |
| `random_forest` | sklearn | `RandomForestClassifier(n_estimators=200)` |
| `mlp` | PyTorch | 全连接网络（展平输入 → hidden → output） |
| `cnn1d` | PyTorch | 1D 卷积网络 |
| `transformer` | PyTorch | 标准 Transformer encoder |
| `itransformer` | PyTorch | 通道独立 Transformer（iTransformer 风格） |
| `proposed` | PyTorch | CAPT-UniShape-RBF-KANFusion |

基线深度模型的默认超参数：
- `hidden_dim=64`, `d_model=64`, `num_layers=2`, `dropout=0.1`
- `lr=1e-3`, `weight_decay=1e-4`
- `batch_size=32`, `epochs=80`, `patience=10`

所提模型的超参数：
- 由 `--proposed-config` 指定的 YAML 文件决定
- `lr=1e-4`, `weight_decay=1e-4`

## 五、实验设计建议

### 5.1 消融实验设计

**推荐的消融变体**（按论文重要性排序）：

| 优先级 | 变体 | 验证的假设 |
|---|---|---|
| P0 | `full_rbf` | 完整模型基准 |
| P0 | `no_rbf` | RBF 动态原型头的贡献 |
| P0 | `no_kan_fusion` | Residual KAN-Fusion 的贡献 |
| P0 | `no_eis_input` | EIS/阻抗形状信息的重要性 |
| P1 | `static_prototype` | 工况感知迁移 vs 静态原型 |
| P1 | `stack_only` | 仅电堆运行序列的能力 |
| P1 | `eis_cond_only` | EIS + 工况的判别力 |
| P2 | `no_transport_reg` | 迁移正则的作用 |
| P2 | `no_separation_reg` | 分离正则的作用 |
| P2 | `no_condition_input` | 工况向量的独立贡献 |

### 5.2 噪声实验设计

**推荐的 SNR 级别**：40, 30, 20, 10, 5, 0 dB（6 档 + clean）

**推荐的对比模型**：logreg, random_forest, mlp, cnn1d, transformer, itransformer, proposed（7 个）

### 5.3 实验一致性要求

为确保消融和噪声实验结果可以放在同一篇论文中：

1. **使用相同的数据文件**：`data/processed/codex_baseline_selected_self_seed44_8_2/official_self_stack_impedance_eis_w64_8_2.npz`
2. **使用相同的 seed**：44
3. **使用相同的训练协议**：
   - epochs=80, patience=10, min_epochs_before_stop=20
   - batch_size=32, lr=1e-4, weight_decay=1e-4
   - class_weighting=sqrt_balanced
   - val_metric_smoothing=3
   - refit_trainval=False
   - checkpoint_selection=best_val
4. **消融实验的 full_rbf 基准应与噪声实验的 proposed clean 结果一致**

run_evaluation(
    config_path: str,       # YAML 配置路径

### 7.3 模型构建

```python
from models import build_model_from_config

config = {
    "use_rbf_head": True,  # True → RBF版, False → NoRBF版
    "use_residual_kan_fusion": True,
    "use_condition_transport": True,
    "d_model": 96,
    # ... 其他参数
}
model = build_model_from_config(config)
```

### 7.4 消融开关参数

| 参数 | 默认值 | 设为 False/0 的效果 |
|---|---|---|
| `use_rbf_head` | True | 使用 NoRBF 模型（MLP 分类头） |
| `use_residual_kan_fusion` | True | 关闭 KAN 残差分支，只保留 MLP 融合 |
| `use_condition_transport` | True | 关闭工况迁移，使用静态原型 |
| `alpha_transport` | 0.001 | 设为 0 → 去掉迁移正则 |
| `alpha_sep` | 0.001 | 设为 0 → 去掉分离正则 |
| `alpha_kan` | 0.0001 | 设为 0 → 去掉 KAN 正则 |
