## 一、论文标题与核心主张

**论文标题建议**：CAPT-UniShape: Condition-Aware Prototype Transport for Multi-Modal PEMFC Fault Classification

**核心主张**：
1. 提出 CAPT-UniShape 模型，融合电堆运行序列、EIS/阻抗形状序列和**独立工况变量**三种正交输入，用于 PEMFC 故障分类。
2. 引入 Residual KAN-Fusion 实现多源非线性特征融合。
3. 引入 RBF 工况感知动态原型分类头（CAPT），使类别原型随工况自适应迁移。
4. 在自测 PEMFC 数据集和公开 AC Voltage Response 数据集上验证模型有效性。

## 二、模型结构摘要（供方法章节使用）

### 2.1 输入（三路正交，无信息冗余）

| 输入 | 符号 | 形状 | 含义 | 信息来源 |
|---|---|---|---|---|
| 电堆运行序列 | x_op | [B, 3, 64] | 电堆总电压、总电流、功率时间序列 | 运行状态动态 |
| EIS/阻抗形状序列 | x_eis | [B, 4, 128] | 由 9 个阻抗统计量构造的 4 通道形状序列 | 阻抗/EIS 特征 |
| 工况变量 | x_cond | [B, 7] | 7 个独立工况变量（压力/温度/压降/温升） | 独立工况条件 |

**x_cond 的 7 个特征**（经 RF 重要性 + ANOVA F 检验 + 相关性去冗余筛选）：

| 特征 | 物理含义 | 选择理由 |
|---|---|---|
| 进堆空压 | 空气侧压力代表 | 压力组代表，RF=0.117 |
| 出堆水温 | 冷却系统温度 | 温度组代表，F=5152 |
| 高压水泵转速FK | 冷却系统控制量 | 控制组代表，F=30564 |
| 氢压差 | 氢气侧压降 | 独立，RF=0.08, F=19217 |
| 空压差 | 空气侧压降 | 独立，RF=0.11, F=21461 |
| 水温升 | 冷却水温升 | 独立，F=18489 |
| FC空压机出口温度 | 压缩热指标 | RF=0.06, F=11278 |

**设计原则**：x_cond 与 x_op、x_eis 之间不存在信息冗余。x_op 捕捉运行状态的时序动态，x_eis 编码阻抗统计的形状特征，x_cond 提供独立的环境/工况上下文。

### 2.2 模块组成

| 模块 | 作用 |
|---|---|
| Official UniShape Backbone ×2 | 分别编码 x_op 和 x_eis 的多尺度形状特征（共享结构、不共享权重） |
| Condition Encoder | MLP 将 7 维 x_cond 映射到 d_model 维条件 token |
| Residual KAN-Fusion | MLP 主分支 + KAN 残差分支融合三类特征 |
| RBF Prototype Head (CAPT) | 静态原型 + RBF 工况偏移 → 余弦/温度分类 |

### 2.3 损失函数

```
L = L_wce + α_transport·L_transport + α_sep·L_sep + α_kan·L_kan
```

- L_wce：sqrt_balanced 类别加权交叉熵
- L_transport：原型迁移幅值正则（α=0.001）
- L_sep：原型分离正则（α=0.001）
- L_kan：KAN 基函数正则（α=0.0001）

### 2.4 关键超参数（当前配置）

所提模型和所有对比模型的完整超参数、训练配置详见 `configs/current_comparison_models.yaml`

## 三、实验设置摘要（供实验章节使用）

### 3.1 数据

- 来源：`data/raw/水淹和膜干故障测试数据_补充特征汇总.xlsx`
- 总记录：11,137 条
- 三分类：正常=0（1,752 条）、过干=1（2,036 条）、过湿=2（7,349 条）
- 滑动窗口：window_size=64, stride_train=16, stride_eval=32
- EIS 构造：9 个阻抗统计量插值到 128 点 + 一阶差分 + 累积形状 + 频率坐标 → 4 通道

### 3.2 数据划分

- 基于连续工况片段的分组分层划分（segment_gap=60s, block=300s）
- 60s 阈值依据：数据中 196 个位置间隔 > 1s，仅 10 个位置间隔 > 60s
- group_split_strategy: holdout_first
- 归一化统计量仅由训练集计算
- 标签变化也触发新 segment（防止窗口跨越故障边界）

### 3.3 四个比例的数据规模

| 比例 | 总样本 | 训练 | 验证 | 测试 |
|---|---|---|---|---|
| 8:2 | 437 | 317 | 54 | 66 |
| 7:3 | 412 | 262 | 57 | 93 |
| 6:4 | 393 | 224 | 47 | 122 |
| 5:5 | 374 | 184 | 37 | 153 |

### 3.4 训练

- 优化器：AdamW (lr=1e-4, weight_decay=5e-4)
- batch_size=32, epochs=80, patience=10
- 类别权重：sqrt_balanced
- 早停指标：验证集 Macro-F1（5 轮移动平均）
- 选模评分：macro_f1_gap_penalty（0.5×val_macro_f1 + 0.5×(-|train_f1 - val_f1|)）
- 不做 train+val 重训（refit_trainval=False）
- min_epochs_before_stop=30

## 五、消融实验设计

| 变体 | 模块变化 | 预期验证目标 |
|---|---|---|
| full_rbf | 完整模型 | 基准 |
| no_rbf | 去掉 RBF 动态原型头 → MLP 分类头 | 验证 CAPT 头贡献 |
| no_kan_fusion | 去掉 KAN 残差分支 → 纯 MLP 融合 | 验证 KAN 融合贡献 |
| static_prototype | 保留原型但关闭工况迁移 | 验证工况感知迁移贡献 |
| no_transport_reg | 去掉原型迁移正则 | 验证正则项作用 |
| no_separation_reg | 去掉原型分离正则 | 验证正则项作用 |
| no_eis_input | 置零 EIS 分支 | 验证 EIS 输入贡献 |
| no_condition_input | 置零工况向量 | 验证独立工况变量贡献 |
| stack_only | 仅电堆运行分支 | 验证多源融合必要性 |
| eis_cond_only | 仅 EIS + 工况 | 验证运行序列贡献 |

**关键预期**：由于 x_cond 现在包含独立工况信息（压力/温度/压降），`no_condition_input` 应该能看到明显的性能下降（不同于旧版冗余 x_cond 下的 100%）。

## 八、论文写作注意事项

### 必须做的

1. 同时报告 Accuracy 和 Macro-F1
2. 报告第0类 Recall/F1 和 Support
3. 说明 x_cond 的特征筛选过程（RF + ANOVA + 去冗余）
4. 强调三路输入信息正交的设计原则
5. 消融实验中如果 no_condition_input 性能下降，说明独立工况变量确实有贡献

### 不能做的

1. 不能宣称"所有设置下均显著优于所有基线"
2. 不能只报告最优单次结果而完全省略多 seed 波动
3. 不能把噪声增强训练的结果混入干净训练主结果表
